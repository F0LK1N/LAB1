# Factory Method + Prototype (Windows Forms)

Лабораторная работа на C#: случайный выбор фигуры из конечного набора,
суперфигуры с большим числом клеток и создание копий фигур.

## Что делает программа

- По кнопке **«Сгенерировать фигуру»** случайно выбирается фабрика и создаётся фигура.
- Обычные фигуры состоят из 4 клеток, суперфигуры — из 5 и более.
- Суперфигура появляется с вероятностью 20%.
- По кнопке **«Создать копию»** вызывается `Clone()` и копия отображается справа.
- Оригинал и копия выводятся в отдельных `PictureBox`.

## Паттерны

**Factory Method** — в `FigureFactory.cs`:

```csharp
public abstract class FigureFactory
{
    public abstract Figure CreateFigure();
}
```

Каждая конкретная фабрика создаёт свой тип фигуры.

**Prototype** — в `Figure.cs`:

```csharp
public abstract Figure Clone();
```

У каждой фигуры есть конструктор копирования, который создаёт новый список клеток.
